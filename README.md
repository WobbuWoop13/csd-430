# CSD 430 – Server Side Development
<sub>Bellevue University · Portfolio Repository</sub>

---

## Overview
This repository contains selected coursework from **CSD 430: Server Side Development**, organized to demonstrate progressive mastery of **Java-based server-side web development**. The projects focus on building dynamic, database-backed web applications using **JavaServer Pages (JSP)**, **JDBC**, and **MySQL**, following MVC-style architectural patterns.

Rather than serving as a single deployable application, this repository highlights **incremental development milestones**, each emphasizing a core backend concept used in traditional enterprise Java environments.

---

## Module Highlights

### 🔹 Module 1 – JSP Fundamentals & Server-Side Rendering
📁 `module-1/`

**Focus:** Introduction to server-side Java web development  
- JSP syntax and scriptlets  
- Server-side rendering of dynamic content  
- Understanding the JSP request/response lifecycle  

---

### 🔹 Module 2 – JSP Forms & Request Processing
📁 `module-2/`

**Focus:** Handling user input  
- HTML form submission  
- Request parameter processing in JSP  
- Dynamic output generation  

---

### 🔹 Module 4 – JavaBeans & MVC Foundations (Movie Bean)
📁 `module-4/`

**Focus:** Separation of concerns  
- JavaBeans for data encapsulation  
- JSP integration with backend objects  
- MVC-style application structure  

---

### 🔹 Module 6 – JDBC Database Integration
📁 `module-6/`

**Focus:** Database connectivity  
- JDBC integration with MySQL  
- Executing SQL queries from Java  
- Rendering database-driven content in JSP  

---

### 🔹 Module 7 – Full CRUD Web Application
📁 `module-7/`

**Focus:** End-to-end CRUD workflows  
- Create, Read, Update, Delete operations  
- Server-side form handling  
- JDBC-powered data manipulation  

---

### 🔹 Module 8 – Movie Database Web Application
📁 `module-8/`

**Focus:** Complete database-backed application  
- Movie database management system  
- JavaBeans / DAO patterns  
- MVC-style architecture  
- Dynamic JSP rendering  

---

### 🔹 Module 9 – Enhanced Movie Database Application
📁 `module-9/`

**Focus:** Refinement and enhancement  
- Improved application structure  
- Cleaner data handling  
- Preparation for production-style improvements
